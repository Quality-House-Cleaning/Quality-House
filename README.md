# Quality House Cleaning

Independent static rebuild of the Quality House Cleaning website, created to replace the Base44-hosted version.

## Deployment

The site is ready to publish with GitHub Pages from the `main` branch/root directory.

## Files

- `index.html` — site content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, animations, and estimate form

The estimate form opens a pre-filled email to `qualityhouse2027@gmail.com`. Square checkout links can be connected when the original booking URLs are available.
